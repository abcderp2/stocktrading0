# 株価あそび場

公開サイト

https://abcderp2.github.io/stocktrading0/

GitHubリポジトリ

https://github.com/abcderp2/stocktrading0

実在の銘柄や実際の株価データを使わず、1つの「テスト企業」の名前、株価、時価総額、PER、値動きなどを自由に動かして遊ぶ株価サンドボックスです。

## 使い方

最初に覚える操作は3つだけです。

1. 「テスト企業」の名前を好きな名前へ変える
2. 株価スライダー、数値入力、またはチャート右側の「上下に動かす」で株価を変える
3. 「買う」「売る」「1日進める」を押して結果を見る

変更はその場で反映されます。「反映」ボタンはありません。

## 主な機能

- 初期企業名は「テスト企業」
- 企業の追加、削除、銘柄選択はなく、1つの企業だけを自由に編集
- 会社名と銘柄コードを自由入力
- 株価は0.01円から1兆円まで設定可能
- 株価、時価総額、PER、値動きの激しさ、上がりやすさ、市場ムードをスライダー操作
- 数値欄へ直接入力してスライダー範囲外の値も設定可能
- チャート右側の専用つまみを上下ドラッグして株価を直接変更
- チャートの横移動、拡大縮小、最新位置への復帰
- 株価を-20%、-5%、+5%、+20%へすぐ動かすボタン
- 1日、5日、20日の時間進行と自動再生
- 架空資金による買いと売り
- 10株、100株、1000株の数量プリセット
- 任意で空売り、現金マイナス、取引コストを有効化
- 1つ前の状態へ戻す
- 初期状態へ戻す
- ブラウザー内の自動保存
- JSONバックアップと復元
- 旧版v1保存データから、選択していた1銘柄をv2へ移行

表示される企業、株価、指標、値動き、損益はすべて架空です。投資助言、実際の市場データ、将来予測ではありません。

## 技術構成

無料プランのAIと、エントリークラスのスマートフォンまたはタブレットでも保守しやすい構成を維持します。

- HTML5
- CSS3
- Vanilla JavaScript
- Canvas 2D
- localStorage
- Python標準ライブラリによる静的検査
- Node.js標準機能だけのスモークテスト
- 外部Actionを使わないGitHub Actions
- GitHub Pages

npm、フレームワーク、ビルドツール、データベース、バックエンド、外部CDN、外部フォント、広告、アクセス解析、外部株価API、有料APIは使いません。

## 端末への配慮

- 320px程度のスマートフォンからPCまでレスポンシブ表示
- 主要ボタンと入力欄は44px以上を基本
- Canvasの高DPI倍率は最大1.5倍
- 1銘柄だけを扱いDOM量と保存量を抑制
- ローソク足は最大1200本
- 取引履歴は最大300件
- 自動保存は約0.9秒デバウンス
- バックグラウンドへ移動すると自動再生を停止して保存
- `prefers-reduced-motion`へ対応
- チャート操作が難しい端末でもボタンで過去移動と拡大縮小が可能

## セキュリティとプライバシー

サイトの通常動作に外部通信は不要です。APIキー、パスワード、アクセストークン、個人情報を入力する機能はありません。

自由入力はHTMLとして実行せず、DOMの文字列として扱います。保存JSONはサイズ、スキーマ、数値範囲、ローソク足順序などを検証します。CSPでは`connect-src 'none'`を指定し、意図しない外部通信を抑制します。

詳細は[SECURITY.md](SECURITY.md)を参照してください。

## 保存形式とやり直し

新しい画面は`stocktrading0.state.v2`へ保存します。旧版の`stocktrading0.state.v1`は自動削除しません。

初回にv2保存がなくv1保存がある場合、旧版で選択していた銘柄だけを新しい1企業モードへ移します。旧版保存自体は残るため、コードをRevertした場合の復旧余地を残します。

画面上では「1つ戻す」「最初から」を常に利用できます。完全バックアップはJSON書き出しを使います。
