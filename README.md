# 株価あそび場

公開サイト

https://abcderp2.github.io/stocktrading0/

GitHubリポジトリ

https://github.com/abcderp2/stocktrading0

実在の株価や企業データを使わず、1つの「テスト企業」を自由に動かして遊ぶ架空株価サンドボックスです。初期現在株価は1,000円です。

## まず覚える操作

1. 株価スライダー、数値入力、またはチャート右側の「現在値を上下」で現在株価を変える
2. チャートを指やマウスで横に滑らせると、その位置の日付、始値、高値、安値、終値、騰落、値幅、出来高が追従する
3. 「買う」「売る」「1日進める」を使う
4. 非現実な動きが欲しいときは「ありえない事件を起こす」を使う

「最初から」は確認ダイアログを出さず、1回押すと即座に初期状態へ戻ります。押し間違えた場合は「1つ戻す」で直前へ戻せます。

## 現実っぽい要素

- 端末の日付を基準に約20年分の架空日足を初期生成
- 初期現在株価は必ず1,000円
- 日付と曜日
- 日足、週足、月足
- 1か月、3か月、1年、5年、20年、全期間
- OHLC
- 架空出来高
- 52週高値、52週安値
- 約20年高値、約20年安値
- 時価総額、PER
- ローソク足と出来高を同じCanvasに表示
- 売買履歴に市場日付を保存
- 平日と簡易年末年始休場を使う市場カレンダー

平日市場の休場日は、土日と年末年始の一部だけを簡略化した架空ルールです。実際のJPXなどの取引所カレンダーではありません。

## 非現実な要素

現実らしい見た目のまま、数字は自由です。

- 株価0.01円から1兆円
- 時価総額とPERを株価と無関係に設定可能
- 極端な値動き
- 「謎の大発見 +80%」
- 「社長が月を買った +300%」
- 「原因不明 -60%」
- 「相場がバグる ランダム」
- 365日市場
- 空売り、現金マイナス、取引コストの任意設定

表示される価格、出来高、指標、売買、事件はすべて架空です。投資助言、実際の市場データ、将来予測ではありません。

## チャート操作

スマートフォン、タブレット、PCで同じ基本操作を使います。

- 1本指またはマウスで横に滑らせる: 過去へ移動しながら、その位置の値を連続表示
- マウスホイールまたは2本指: 拡大縮小
- 「過去へ」「新しい方へ」: タッチ操作が難しい場合の代替
- 「選択期間を一望」: 可能な範囲で選択期間全体を表示
- 「最新へ戻る」: 最新側へ戻す
- 右側の「現在値を上下」: 現在株価そのものを変更

一般的な株価アプリで広く使われる、期間切替、横方向のチャート移動、追従する価格確認、OHLC、出来高という操作原則だけを参考にしています。特定アプリの配色、画面構成、アイコン、画像、文章、コードはコピーしません。

## エントリークラス端末への配慮

- 320px程度のスマートフォンからPCまでレスポンシブ
- 主要操作は44px以上を基本
- CanvasのdevicePixelRatioは最大1.5
- 1企業だけ
- 最大7,500本の日足
- 通常の平日市場では約20年分が約5,000本台
- 日足だけを保存し、週足と月足は表示時に集計
- Canvasは画面に見える最大320本程度だけを描画
- Undoは最大3状態に抑える
- 自動保存は約1秒デバウンス
- バックグラウンドへ移動すると自動再生を停止して保存
- `prefers-reduced-motion`対応
- チャートを指で操作できない場合もボタンで移動、拡大縮小可能

20年分の履歴を持っていても、毎回7,500本をCanvasへ描画しません。

## 保存とやり直し

現在の保存キー

`stocktrading0.state.v4`

v4では日足に日付、OHLC、出来高を保存します。

旧保存キー

- `stocktrading0.state.v3`
- `stocktrading0.state.v2`
- `stocktrading0.state.v1`

旧保存は自動削除しません。読み込める旧データはv4へ移し、足りない過去期間には架空の長期履歴を補います。

やり直し手段

- 「1つ戻す」
- 「最初から」
- JSONバックアップ
- GitHubのSquashコミットをRevert

## セキュリティとプライバシー

通常動作はブラウザー内で完結します。実行時に外部API通信を必要としません。

主な対策

- CSPで`connect-src 'none'`
- `innerHTML`、`eval`など危険なDOM・コード実行APIを使用しない
- `fetch`、WebSocketなど外部通信APIを公開JavaScriptで使用しない
- 自由入力から制御文字と双方向制御文字を除去
- JSONのサイズ、スキーマ、数値上限、日付順序を検証
- localStorage保存を約2.5MB以下に制限
- JSON入出力を8MB以下に制限
- GitHub Actionsで秘密情報らしい文字列をGit履歴まで監査
- 外部JavaScript、外部CSS、外部フォントを読み込まない

詳細は[SECURITY.md](SECURITY.md)を参照してください。
